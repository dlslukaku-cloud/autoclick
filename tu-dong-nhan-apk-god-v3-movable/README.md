# Tự động nhấn — APK GOD V3


## V3.2 — Movable Click Markers

Edit Mode now supports draggable TAP markers:
- Open the floating editor and enable **Edit Mode**.
- Every TAP action appears as a `✚` marker at its X/Y coordinate.
- Drag a marker to move the click position.
- Releasing the marker updates the corresponding macro action.
- The floating control bubble remains separate from click markers.
